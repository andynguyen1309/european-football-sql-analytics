# Analytical Outputs

This directory contains **CSV extracts generated by the project’s SQL analysis and export queries**.

The output files are derived analytical datasets rather than raw source data.

## Purpose

The CSV outputs serve two main purposes:

1. preserve selected business-question results generated in PostgreSQL; and
2. provide clean, dashboard-ready data sources for Tableau.

The analytical logic remains in the `sql/` directory. These CSV files should therefore be viewed as **results of the SQL workflow**, not as manually prepared datasets.

## Folder Structure

```text
outputs/
├── README.md
├── theme_1/
├── theme_2/
├── theme_3/
├── theme_4/
└── theme_5/
```

### Theme 1 — Club and League Performance

Contains outputs used for club-season rankings, trends, home/away comparisons, league scoring analysis and market-value-adjusted performance.

Examples may include:

- club-season performance
- five-season club summaries
- club trends
- home/away comparison
- league goal comparison
- performance efficiency

### Theme 2 — Player Performance and Consistency

Contains outputs for:

- player-season productivity
- goal involvement
- position rankings
- year-on-year improvement
- sustained performance
- under-23 playing time
- lower-performing-club players
- productivity and availability

### Theme 3 — Market Value and Player Development

Contains outputs for:

- absolute and percentage market-value growth
- under-23 value development
- club-level value growth
- high-growth player counts
- under-23 league value
- positional median value
- peak-value age
- performance/value change comparisons

### Theme 4 — Recruitment and Potentially Undervalued Talent

Contains recruitment decision-support outputs such as:

- position-adjusted player performance
- value-opportunity candidates
- performance relative to estimated value
- non-elite-club opportunities
- recent improvement
- meaningful-playing-time candidates
- position-specific shortlists
- final recruitment classifications

### Theme 5 — Transfers and Post-Transfer Outcomes

Contains outputs for:

- known club transfer expenditure and income
- known-fee net balances
- league transfer flows
- transfer routes
- fee profiles by age and position
- post-transfer valuation change
- post-transfer sporting outcomes
- young-acquisition development
- development efficiency relative to known spending

## Relationship to Tableau

Selected files in these folders are used as Tableau data sources.

The workflow is:

```text
PostgreSQL analysis
      ↓
Theme-specific export query
      ↓
CSV output
      ↓
Tableau worksheet/dashboard
```

The final visualisations are stored separately under:

```text
images/theme_1/
images/theme_2/
images/theme_3/
images/theme_4/
images/theme_5/
```

## Reproducibility

These CSVs can be regenerated by running the corresponding SQL analysis/export scripts against the project database.

Because the SQL scripts are the authoritative source of analytical logic, output files should not be edited manually.

## Notes

- Market-value figures represent estimates.
- Transfer financial outputs use known fees where available.
- Missing or undisclosed transfer fees are not treated as zero.
- Some outputs intentionally apply minimum-minute, age, valuation-coverage or transfer-cohort eligibility rules.
- See [`../documentation/methodology.md`](../documentation/methodology.md) for the exact rules used by each theme.
